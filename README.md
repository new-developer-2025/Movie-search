# Netflix Clone App

A Netflix-inspired web application developed to explore modern UI/UX design, responsive layouts, and modular JavaScript architecture. This project simulates core parts of the Netflix browsing experience, including user selection, movie details, and dynamic content rendering.

## ✨ Features

* **Home Page with User Profiles** – Displays selectable users similar to Netflix.
* **Movie Detail Pages** – Each movie has its own page containing full information.
* **Fully Responsive Design** – Adapted for mobile, tablet, and desktop.
* **Netflix-Inspired UI/UX** – Clean layout, cinematic visuals, and smooth navigation.
* **Modular JavaScript Architecture** – Uses ES6 import/export to organize code into reusable components.

---

## 🛠️ Technologies Used

* **HTML5**
* **CSS3 / Responsive Layouts**
* **JavaScript (ES6 Modules)**

---

## 📦 Installation

No installation or setup is required.
Simply download the project and open the `index.html` file in your browser.

---

## 🎯 How It Works

* Select a user from the Home page.
* Browse through available movie thumbnails.
* Click on any movie to view its dedicated detail page.
* All UI elements automatically adapt to the user's screen size.
